# Tic-Tac-Toe

### Live Demo: https://sd-tic-tac-toe.netlify.app/

A modern, responsive, and interactive Tic Tac Toe game built with React and Tailwind CSS, featuring both Player vs CPU and Player vs Player modes. Designed with smooth animations, hover previews, turn indicators, and a smart AI powered by the Minimax algorithm.

# Features

## Game Modes

- 1 Player (VS CPU) - Play against a smart AI.

- 2 Player (VS Player) - Local multiplayer mode.

## CPU Intelligence

- Uses Minimax Algorithm for optimal moves.

- Occasionally performs random moves for more natural gameplay.

- Blocks user input during CPU turn to avoid fast tapping mistakes.

## UI & UX

- Clean, responsive UI.
- Hover previews showing the next move (X or O).
- Turn indicator for clarity.
- Smooth transitions and intuitive layout.
- Mobile-friendly.

## Score Tracking

- Tracks Player Wins, CPU Wins, and Ties.

- Scores persist during session until restart.

# Getting Started

1. Clone the repository

```
git clone https://github.com/danielace1/react-js-mini-projects.git
```

- Navigate to the Tic-Tac-Toe project directory

```
cd tic-tac-toe-game
```

2. Install dependencies

```
npm install
```

3. Run the development server

```
npm run dev
```

4. Open the game in your browser:

```
http://localhost:5173
```
