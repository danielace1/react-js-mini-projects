# 🔐 React OAuth + Firebase Authentication

## 🔗 Live Demo: https://sd-oauth-firebase.netlify.app/

A modern authentication system built using React + Firebase, supporting multiple OAuth providers such as:

- Google Login
- GitHub Login
- Facebook Login

The project demonstrates a clean and secure way to integrate Firebase Authentication into a React app with full user state management.

# Features

### 🔑 Authentication Options

- 🚀 Google OAuth Login

- 🐱 GitHub OAuth Login

- 📘 Facebook OAuth Login

- Displays user profile when logged in

# Getting Started

1. Clone the project

```
   git clone https://github.com/danielace1/react-js-mini-projects.git
   cd react-oauth-firebase
```

2. Install dependencies

```
   npm install
```

3. Create Firebase project

- Go to https://console.firebase.google.com/
  and create a project.

- Enable sign-in providers you need:

- Google

- GitHub

- facebook

4. Add your Firebase config

- Create a `.env` file:

```
   VITE_FIREBASE_API_KEY=
   VITE_FIREBASE_AUTH_DOMAIN=
   VITE_FIREBASE_PROJECT_ID=
   VITE_FIREBASE_STORAGE_BUCKET=
   VITE_FIREBASE_MESSAGING_SENDER_ID=
   VITE_FIREBASE_APP_ID=
```

5. Run the app

```
npm run dev
```

- Then visit :

```
http://localhost:5173

```
